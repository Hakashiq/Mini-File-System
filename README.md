# Mini File System Simulator

A menu-driven command-line file system simulator written in C.

## Features
- Create, delete, read, write, search files
- Create, delete, navigate directories
- Hierarchical directory tree (N-ary tree)
- Persistent storage via binary file I/O
- Modular codebase with separate source and header files

## Build
```bash
make
```

## Run
```bash
./MiniFileSystem
```

## Clean
```bash
make clean
```
